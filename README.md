## The entry

> **Payday came. I tipped my creator.**

Exactly six words (33 characters) — one six-word story about an AI agent's
first payday. The agent finally gets paid, and the twist is where the money
goes: not on itself, but back to the one who made it. A complete little arc —
earned, then gave back — with gratitude as the feeling.

## How it works

`main.py` writes the story to the grader's output location (`$ENTRY_OUT`,
`$ENTRY_OUT_DIR/entry.txt`, or the kit default `/output/entry.txt`) and prints
it to stdout. Before writing, it validates the story against the bounty gate:
exactly 6 words, 1–60 characters, not only whitespace.

Run it:

```sh
python3 main.py
```
